# Tiano Piles

Arcade piano tiles. Four lanes, tiles fall and speed up forever, one wrong tap and you're out. Every tap plays the next note of Bach's Bourrée in E minor (BWV 996). Shows live taps per second and saves your high score. No ads, works offline once installed.

**Play / install:** https://christiaanpbotha.github.io/tiano-piles/

- Android (Chrome): open the link → menu ⋮ → *Install app* / *Add to Home screen*
- iPhone (Safari): open the link → Share → *Add to Home Screen*

Keyboard: D F J K.
